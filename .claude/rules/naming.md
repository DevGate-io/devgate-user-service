# Naming conventions

## Language

- All generated code must be in English: class/function/variable/constant names.
- All text in code must be in English: comments, exception messages, log messages.
- Git commits — in Russian (matches repo history), conventional-style (`feat:`, `fix:`, ...).

## Code comments

- Code should be self-documenting.
- Do not add obvious comments (`// get user`, `// return result`).
- Comments only for:
  - Complex business logic that cannot be simplified.
  - Non-obvious decisions, with a "why" explanation.
  - TODO/FIXME with a task reference.
